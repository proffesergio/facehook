# Facehook - Admin Setup Instructions

## Overview
The Facehook Admin Control Panel is accessible at `/admin`. It provides real-time monitoring of campus feed activity, marketplace transactions, user role definitions, and plain-password inspection for teaching web security concepts.

## Features
1. **Analytics Dashboard (`/admin`)**: Visualizes user counts, feed stats, and engagement metrics.
2. **Item Management (`/admin/items`)**: Responsive list interface that transforms into stacked cards on mobile viewports.
3. **User Management (`/admin/users`)**: Demonstrates user creation and plain-password storage for classroom presentation.
4. **Global Feature Settings (`/admin/settings`)**: Live toggles for site features.
