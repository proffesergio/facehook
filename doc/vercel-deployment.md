# Facehook - Vercel Deployment Instructions

## Automatic Deployment via Vercel CLI
1. Install Vercel CLI:
   `npm install -g vercel`
2. Authenticate:
   `vercel login`
3. Deploy to production:
   `vercel --prod`

## Manual GitHub Integration
1. Push your repository to GitHub as `facehook`.
2. Visit [Vercel Dashboard](https://vercel.com/new).
3. Select `facehook` repository.
4. Framework Preset: **Next.js**.
5. Click **Deploy**.
